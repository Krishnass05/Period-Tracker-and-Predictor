# Period-Tracker-and-Predictor
Built a machine learning-based Period Tracker and Predictor that analyzes historical cycle data to forecast future periods. Implemented data preprocessing and pattern analysis for improved accuracy. Developed a user-friendly interface with backend integration using MySQL.
